# HelpfulHook - Life Below Water

A web application supporting the fishery industry by providing weather forecasts and sustainable fishing assistance.

## ✨ Features
- Weather forecasting system for fishermen
- Community resources for safer fishing practices
- API-based weather data integration

## 🛠 Tech Stack
- ReactJS
- ExpressJS
- Node.js
- MongoDB
- Bootstrap
- Postman

## 🚀 How to Run
1. Clone the repository
2. Install dependencies for client and server
3. Set up MongoDB
4. Start frontend and backend servers
